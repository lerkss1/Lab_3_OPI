# Lab_3_OPI
Практическая работа №3
Дисциплина: Основы программной инженерии Выполнилa: Гиз Валерия Группа: 261
Описание заданий:
A1.py — Определяет, лежат ли две точки (введенные пользователем) в одной координатной четверти. Если да, выводит номер четверти.
A2.py — Проверяет введенный пароль на надежность (длина 8 символов, наличие заглавных/строчных букв, цифр и спецсимволов *, -, #). Выводит список всех ошибок, если они есть.
A3.py — Рассчитывает объем потребленного газа по показаниям счетчика (с учетом перехода через 9999), вычисляет стоимость по тарифной сетке и среднюю цену за кубометр.

Инструкция по запуску:
Для запуска программ требуется установленный Python 3.x.
Скачайте файлы из репозитория или склонируйте его
Откройте терминал (или командную строку) в папке с файлами.
Запустите нужную программу командой: python A1.py (или A2.py, A3.py).
